# Energy — Roadmap

> 一句话：拍一张食物照片，AI 告诉你吃了多少卡路里。

## 技术栈

| 层 | 选型 | 职责 |
|---|---|---|
| 前端 | Expo 57 + React Native + Expo Router | 拍照、压缩、展示结果 |
| 后端 | PocketBase (自定义 API) | 隐藏 AI Key、调用视觉模型、校验结果 |
| AI | 视觉模型（待选型） | 食物识别 + 营养估算 |
| 数据库 | PocketBase 内置 SQLite | 第二阶段保存饮食记录 |

## 阶段划分

### 阶段 1：拍照 → AI 分析 → 显示结果（V1）
核心闭环。验证"照片能稳定到达结果页"。

### 阶段 2：用户确认/修正 → 保存饮食日记
用户可编辑 AI 结果，确认后存入数据库，支持查看历史。

### 阶段 3（远期）
- 用户登录 / 注册
- 每日目标卡路里
- 数据统计与图表
- 多语言支持

## 开发原则

- **小步验证**：每完成一步都确保能跑通，再进入下一步
- **先跑通再优化**：先用假数据、再接真实接口
- **AI Key 安全**：永远不暴露在客户端
- **不提前设计**：不需要的功能不写，不提前建表
