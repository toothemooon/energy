# V1 — MVP 开发计划

> 目标：拍照 → Base64 图片 → AI 识别能量 → 自动保存 → 查看记录 → 付费订阅

## 成功标准

### Gate 1：AI Magic（9/20 前完成）

用户能完成以下完整流程，且中途无报错：

1. 拍照或从相册选一张食物照片
2. 看到加载动画
3. 看到识别结果：energyKcal（例如 642 kcal）
4. 如果图片不是食物，给出友好提示

### Phase 1 数据流

```
App 拍照或选择图片
  ↓
App 压缩图片并转换为 Base64 Data URL
  ↓
App 通过 POST JSON 发送给 PocketBase
  ↓
PocketBase 不保存图片，直接转发给 DeepSeek Vision
  ↓
DeepSeek 返回 AI 分析结果
  ↓
PocketBase 提取并整理为统一格式
  ↓
PocketBase 返回结构化分析 JSON 给 App
  ↓
App 删除临时图片文件
```

### 当前进度（截至 9/14）

已完成并验证：

- App 拍照 / 选图、压缩 JPEG、转换 Base64 Data URL
- App 通过 POST JSON 将图片发送给 PocketBase
- PocketBase 读取 API Key，并调用 DeepSeek Responses API
- 关闭 reasoning，禁止 tool 调用
- DeepSeek 返回 JSON 字符串，PocketBase 解析后返回结构化 JSON
- App 已在 Console 中收到并打印分析结果

当前仍未完成：

- App 结果页面（目前只在 Console 显示）
- 加载状态、错误状态
- 临时图片文件删除
- JSON 字段校验和请求重试
- meal_logs 数据保存

当前原型使用的返回字段为 `totalCalories`、`foods`、`message`；最终字段命名仍需统一为产品接口规范。

### Gate 2：Real Tracker（10/5 前完成）

用户可以连续一天只用 CalFast：

1. 早餐拍照 → 保存
2. 午餐拍照 → 保存
3. 晚餐拍照 → 保存
4. Today 页面正确显示当天摄入
5. History 能找到三餐

### Gate 3：Commercial MVP（11/2 前完成）

1. Widget 可以快速进入拍照
2. Siri / Shortcuts 可以触发记录
3. 免费用户有次数限制
4. Pro 用户可以无限记录

## 模块职责

### App 端
- 获取图片（拍照 / 相册选择）
- 压缩图片（长边 ≤ 1024px，≤ 2MB）
- 将压缩图片转换为 Base64 Data URL
- 通过 POST JSON 上传到 PocketBase 自定义路由
- 管理页面状态：初始 / 加载中 / 成功 / 失败（待实现）
- AI 请求完成后删除临时图片文件（待实现）
- 通过 PocketBase SDK 读写 meal_logs 记录

### PocketBase 端
- 匿名用户认证（自动创建）
- 自定义 AI 路由：接收 Base64 Data URL、调用 DeepSeek Vision、返回结构化分析 JSON
- 不保存用户上传的临时图片
- meal_logs Collection：存储饮食记录
- AI Key 通过环境变量保存，不暴露给客户端

### AI 视觉模型
- 使用 DeepSeek V4.1-Flash（API 模型名：`deepseek-flash`）
- 接收 Base64 Data URL 图片
- 识别图片中的食物
- 估算总能量（kcal），当前返回 `totalCalories`

### AI 请求规范
- 使用 OpenAI Responses API，不使用旧的 Chat Completions API
- 请求地址：`POST https://api.deepseek.com/responses`
- 图片通过 `input_image.image_url` 传入 Base64 Data URL
- 文本通过 `input_text` 传入
- 从 `response.output` 中提取 `message` 的 `output_text`
- PocketBase 使用 `$http.send()` 调用，API Key 通过 `$os.getenv()` 读取

官方文档：
- [DeepSeek Responses API](https://api-docs.deepseek.com/api/create-response/)
- [DeepSeek Responses API Guide](https://api-docs.deepseek.com/guides/responses_api/)
- [OpenAI Responses API 图片输入](https://platform.openai.com/docs/api-reference/responses-streaming/response/refusal?lang=node)
