# V1 — 最小闭环

> 目标：拍照/选图 → AI 识别食物 → 显示总卡路里

## 成功标准

用户能完成以下完整流程，且中途无报错：

1. 打开 App，看到"拍照"按钮
2. 拍照或从相册选一张食物照片
3. 看到加载动画（不是空白页）
4. 看到识别结果：总卡路里 + 每个食物的明细
5. 如果图片不是食物，给出友好提示

## 模块职责

### App 端
- 获取图片（拍照 / 相册选择）
- 压缩图片（长边 ≤ 1024px，≤ 2MB）
- 上传到 PocketBase API
- 管理页面状态：初始 / 加载中 / 成功 / 失败

### PocketBase 端
- 接收 multipart/form-data 图片
- 校验：文件类型、大小
- 调用视觉模型（AI Key 仅存服务端）
- 解析模型返回，标准化 JSON
- 统一错误码（400 / 413 / 422 / 502 / 504）

### AI 视觉模型
- 识别图片中的食物
- 估算分量
- 返回卡路里、蛋白质、碳水、脂肪

## API 设计

```
POST /api/ai/analyze-food
Content-Type: multipart/form-data

Fields:
  image: File（JPEG/PNG/HEIC）
  locale: "en-US"
```

响应格式：

```json
{
  "status": "ok",
  "totalCalories": 680,
  "macros": {
    "proteinG": 35,
    "carbsG": 78,
    "fatG": 22
  },
  "items": [
    {
      "name": "Grilled chicken",
      "portion": "150g",
      "calories": 280,
      "proteinG": 32,
      "carbsG": 0,
      "fatG": 14
    }
  ],
  "confidence": "medium",
  "assumptions": ["Estimated using a standard restaurant serving"]
}
```

## 前端状态机

```
INITIAL  →  用户点击拍照/选图
    ↓
ANALYZING  →  上传中 + 等待 AI 返回
    ↓ (成功)         ↓ (失败)
SUCCESS             ERROR
显示结果             提示重试
```

## 分步实现计划

每一步完成后验证，再进入下一步：

| # | 步骤 | 依赖 | 验证方式 |
|---|------|------|----------|
| 1 | 拍照/选图页面 | `expo-image-picker` | 能获取图片 URI 并显示预览 |
| 2 | 图片压缩 | `expo-image-manipulator` | 压缩后图片尺寸 ≤ 1024px |
| 3 | PocketBase 假接口 | PocketBase 自定义路由 | 返回固定 JSON，App 能解析 |
| 4 | App 接入假接口 | 步骤 1-3 完成 | 走通完整 UI 流程（用假数据） |
| 5 | PocketBase 接入真实 AI | 视觉模型选型完成 | 返回真实识别结果 |
| 6 | 错误处理与重试 | 步骤 5 完成 | 非食物图片 → 友好提示 |

## 不做（V1 明确排除）

- ❌ 保存图片到服务器
- ❌ 用户登录 / 注册
- ❌ 数据库写入

- ❌ 任务队列 / 异步处理
- ❌ 多 AI Provider 切换
- ❌ 图片缓存
