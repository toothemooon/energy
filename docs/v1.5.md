# V1.5 首页基础 UI 实现计划

> **For agentic workers:** 本计划按小步任务执行；每完成一个任务都先运行并确认，再进入下一步。

**目标：** 将当前已经跑通 AI 流程的调试首页，整理为接近参考图的基础 CalFast 首页。

**架构：** 保留现有 App → PocketBase → DeepSeek Responses API 数据流。首页负责布局、结果状态和展示；图片组件继续负责拍照、选图、压缩和 Base64 转换。

**Tech Stack：** Expo SDK 57、React Native、Expo Router、TypeScript、PocketBase Custom Route、DeepSeek Responses API。

**Spec：** `docs/v1.md`

## Global Constraints

- 本阶段只改 App 首页 UI 和必要的组件接口，不修改 PocketBase AI 请求。
- 暂不实现 JSON 校验、请求重试、数据库保存和 History 数据。
- 当前继续使用 `totalCalories`、`foods`、`message` 字段。
- API Key 只能保留在 PocketBase 服务端。
- 编写 Expo 代码前参考 [Expo SDK 57 文档](https://docs.expo.dev/versions/v57.0.0/)。

---

## 当前基线

- 图片选择、JPEG 压缩、Base64 Data URL 已完成。
- App JSON POST 到 PocketBase 已完成。
- PocketBase 调用 DeepSeek Responses API 已完成。
- AI JSON 已能解析并返回 App。
- 当前首页仍显示调试按钮和 Console 结果，尚未形成正式首页布局。

## 目标首页结构

```text
Safe Area
├── 顶部：CalFast + 设置入口占位
├── Today：总热量数字 + kcal
├── 主操作：Take a photo
├── Recent meal：最近图片、热量、时间、说明
└── 底部：Home + History 标签
```

## 实现任务

### Task 1：建立首页视觉骨架

**Files:**
- Modify: `src/app/(tabs)/index.tsx`

**内容：**

- 使用安全区域包住首页内容。
- 将深色调试页面改为浅色背景。
- 添加顶部标题、Today 区域、主按钮区域和 Recent meal 占位区域。
- 先使用静态占位文字，不改变 AI 请求。

**验证：** App 启动后能看到完整的首页区域，且不再只有居中调试内容。

### Task 2：整理拍照和选图入口

**Files:**
- Modify: `src/app/components/ImagePicker.tsx`
- Modify: `src/app/(tabs)/index.tsx`

**内容：**

- 将 `Take a photo` 作为主要入口。
- 保留相册选择能力，但作为次要入口。
- 移除 `test`、`hi` 和 `Press Me` 等调试元素。
- 保持现有 `imageDataUrl` 回调和后端请求流程不变。

**验证：** 点击主要按钮仍能打开相机；选图后仍能完成原有分析请求。

### Task 3：把分析结果显示到首页中央

**Files:**
- Modify: `src/services/api.ts`
- Modify: `src/app/(tabs)/index.tsx`

**接口约定：**

```ts
type Analysis = {
  totalCalories: number;
  foods: { name: string; calories: number }[];
  message: string;
};
```

**内容：**

- `analyzeFood` 返回完整的 `Analysis` 对象。
- 首页通过 `useState<Analysis | null>` 保存结果。
- 请求成功后显示 `totalCalories` 和 `message`。
- 没有结果时显示默认状态，而不是访问 `null` 的属性。

**验证：** 完成一次图片分析后，首页中央能显示实际 AI 返回的总热量。

### Task 4：实现 Recent meal 卡片

**Files:**
- Modify: `src/app/components/ImagePicker.tsx`
- Modify: `src/app/(tabs)/index.tsx`

**接口约定：**

- 图片组件新增一个可选的图片 URI 回调，用于把当前压缩图片 URI 交给首页。
- 分析结果仍通过现有的 `onPress(imageDataUrl)` 传递。

**内容：**

- 首页保存最近一次压缩图片 URI。
- 显示图片、`totalCalories`、`Just now` 和 `message`。
- 没有分析记录时显示空状态卡片。

**验证：** 分析完成后，Recent meal 卡片同时显示图片和分析结果。

### Task 5：整理底部导航和视觉细节

**Files:**
- Modify: `src/app/(tabs)/_layout.tsx`
- Modify: `src/app/(tabs)/about.tsx`

**内容：**

- 将 `profile` 标签改为 `History`。
- 保留 History 页面作为占位页面，不实现历史数据。
- 统一背景色、文字颜色、间距、圆角和按钮样式。

**验证：** 首页底部显示 Home / History，点击 History 能正常导航。

## 本阶段完成标准

- 首页整体结构接近参考图。
- 用户可以从首页进入拍照 / 选图流程。
- AI 分析结果显示在首页，而不只是 Console。
- 最近一次图片和热量显示在 Recent meal 卡片。
- Home / History 导航可用。
- 没有引入 JSON 校验、重试、数据库和新的后端逻辑。
